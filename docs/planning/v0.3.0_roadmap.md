# v0.3.0 Roadmap: Advanced Semantic Analysis

## Goals
- Implement Genre Classification (e.g., Rock, Jazz, Electronic)
- Implement Mood/Emotion Detection (e.g., Happy, Sad, Aggressive)
- Integrate Deep Learning models via `essentia-tensorflow`

## Technical Strategy
1. **Dependency Management**:
   - Add `essentia-tensorflow` (Note: Large binary size)
   - Download pre-trained models (MusiCNN, VGGish)

2. **Architecture**:
   - Create `SemanticAnalyzer` class in `src/mueta/engine/analysis/`
   - Implement model loading and caching (to avoid reloading large models per file)

3. **Models**:
   - **Genre**: `msd-musicnn-1.pb` (MusicCNN trained on Million Song Dataset)
   - **Mood**: `mtg_jamendo_moodtheme-musicnn-1.pb` (Mood/Theme classification)

4. **CLI Updates**:
   - Update `analyze` command to support `--deep` or `--semantic` flag (optional due to speed/resource cost)
   - Update `view-meta` to display Genre/Mood tags

## Risks
- **Package Size**: Binary size will increase significantly.
- **Performance**: Deep learning inference is CPU/RAM intensive.
- **Compatibility**: TensorFlow dependencies can be tricky on some platforms.
