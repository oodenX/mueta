# Mueta v0.3.0 - 语义分析功能

## 版本概述

v0.3.0 版本新增了 **Genre（流派）** 和 **Mood（情绪）** 自动识别功能，采用 **Last.fm API + 深度学习模型** 的混合策略，确保在各种场景下都能获取准确的语义标签。

## 核心特性

### 1. 混合语义分析策略

```
┌─────────────────────────────────────────────────────────────┐
│                    语义分析流程                              │
├─────────────────────────────────────────────────────────────┤
│  1. Last.fm API 查询 (基于 Artist + Title)                  │
│     ├── 成功 → 返回 Genre/Mood 标签                         │
│     └── 失败/空结果 ↓                                       │
│  2. ML Fallback (基于音频内容)                              │
│     ├── Discogs-EfficientNet 提取 Embedding                 │
│     ├── Genre 分类器 (400 类 Discogs 风格)                  │
│     └── Mood 分类器 (56 类 MTG-Jamendo 主题)                │
└─────────────────────────────────────────────────────────────┘
```

### 2. 支持的标签类型

**Genre（流派）**：
- Rock, Pop, Electronic, Jazz, Classical, Hip-Hop, R&B, Metal, Folk, Blues, Reggae, Latin, World, Soundtrack

**Mood（情绪）**：
- Happy, Sad, Chill, Aggressive, Energetic, Dark, Romantic, Party, Focus

## 使用方法

### 基本命令

```bash
# 获取元数据 + 语义分析
mueta get-meta /path/to/audio.flac --analyze

# 批量处理目录
mueta get-meta /path/to/music/ -r --analyze

# 保留原文件（复制而非移动）
mueta get-meta /path/to/music/ -r --analyze --reserve-original

# 仅获取 Genre/Mood（不做完整音频分析）
mueta get-meta /path/to/audio.flac --genre
```

### 查看元数据

```bash
mueta view-meta /path/to/audio.flac
```

## 配置选项

在 `config.toml` 中配置 ML 参数：

```toml
[lastfm]
api_key = "your_lastfm_api_key"
api_secret = ""
enable = true
cache_ttl = 604800  # 7天缓存

[ml]
# 启用 ML fallback
enable = true

# 自定义模型目录（默认: ~/.mueta/models/）
# model_dir = "/path/to/models"

# Genre 预测阈值 (0.0-1.0)
genre_threshold = 0.1

# Mood 预测阈值 (0.0-1.0)
mood_threshold = 0.3

# 最大返回数量
max_genres = 5
max_moods = 3
```

| 组件 | 大小 |
|------|------|
| mueta 源代码 | 596 KB |
| ML 模块 | 76 KB |

### 内存使用分析

```
初始状态           ~22 MB
导入 TensorFlow    ~350 MB  (主要是 TF 运行时)

处理音频           ~850 MB  (音频数据 + 中间结果)
```

> ⚠️ **注意**: ML 模块使用延迟加载策略，只有在需要 ML fallback 时才会加载模型。如果 Last.fm 能返回结果，内存占用会更低。

## 深度学习模型说明

### 使用的模型

1. **Discogs-EfficientNet** (`discogs-effnet-bs64-1.pb`)
   - 用途: 音频 Embedding 提取
   - 输入: 16kHz 单声道音频
   - 输出: 高维特征向量

2. **Genre Discogs400** (`genre_discogs400-discogs-effnet-1.pb`)
   - 用途: 音乐风格分类
   - 类别数: 400 种 Discogs 风格
   - 映射: 自动映射到 14 种主要流派

3. **MTG-Jamendo Mood/Theme** (`mtg_jamendo_moodtheme-discogs-effnet-1.pb`)
   - 用途: 多标签情绪/主题分类
   - 类别数: 56 种情绪/主题
   - 映射: 自动映射到 9 种主要情绪

### 模型来源

所有模型来自 [Essentia Models](https://essentia.upf.edu/models.html)，由 MTG (Music Technology Group) 提供。

## 已知限制

1. **内存占用较高**: TensorFlow 运行时和模型占用约 850MB 内存
2. **首次运行需下载模型**: 约 25MB 模型文件会自动下载到 `~/.mueta/models/`
3. **GPU 未优化**: 当前版本在 CPU 上运行，未使用 CUDA 加速
4. **冷门歌曲**: Last.fm 数据库可能没有冷门歌曲的标签，此时完全依赖 ML 预测
